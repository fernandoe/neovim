# cheatsheet

## nvim

### debug

| mappings     | Description   |
|--------------|---------------|
| `<leader>ui` | Toggle DAP UI |


### git

| mappings     | Description   |
|--------------|---------------|
| `<leader>ge` | Git explorer (NeoTree) |
| `<leader>ge` | Git explorer (NeoTree) |


### quickfix

| mappings   | Description                     |
|------------|---------------------------------|
| `:copen`   | Toggle quickfix window          |
| `:cnext`   | Go to next quickfix item        |
| `:cprev`   | Go to previous quickfix item    |
| `:cfirst`  | Go to first quickfix item       |
| `:clast`   | Go to last quickfix item        |
| `:cc NU`   | Jump to quickfix item number NU |
| `:cclose`  | Close quickfix window           |


### Default Mappings

| mappings   | Description                        |
|------------|------------------------------------|
| `grn`      | Rename symbol                      |
| `grr`      | Find references                    |
| `gri`      | Go to implementation               |
| `g0`       | Go to definition                   |
| `gra`      | Code action                        |
| `CTRL-S`   | Save file                          |
| `[d`       | Go to previous diagnostic          |
| `]d`       | Go to next diagnostic              |
